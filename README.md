## 📌 Overview

SQL Agent is an AI-powered web application that enables users to interact with SQLite databases using plain English. Instead of writing SQL manually, users simply ask questions in natural language, and the application automatically generates, executes, and explains SQL queries using Large Language Models (LLMs).
